# IELTS Writing Lab｜观点表达记忆室（v8：先学后练·单次判定）

这是在上传的 **v7** 静态网站基础上更新的 GitHub Pages 版本，保留原有 **600 条表达、12 个主题分区**、用途筛选、检索、表达总库、每日目标、语音朗读和本地学习进度备份。

## 两种学习流程

**新表达：**
1. 看中文提示，先自行猜想英文表达。
2. 点击「显示英文答案与例句」，查看标准表达、例句、中文释义及用法说明。
3. 点击「我看懂了，隐藏答案并开始拼写」；系统会收起英文答案和例句，避免看着答案照抄。
4. **仅需拼写一次。** 正确即完成首次学习，约 **1 天后**进入间隔复习；不在首次学习环节直接算“已掌握”。错误会在约 **10 分钟后**进入到期复习，本轮不强制再次输入。

**间隔复习：**
1. 先看中文提示（和挖空的语境提示），独立输入英文表达，答案在核对前隐藏。
2. **仅需拼写一次。** 正确即判定为**已掌握**，并安排下一次间隔复习；错误会在约 **10 分钟后**再次到期，不会被添加到本轮队列末尾。
3. 核对后可查看正确答案与语境，再进入下一条。

拼写核验允许大小写差异、连续空格，以及常见弯引号和破折号形式的标准化；其余拼写和词序需与核心英文表达（或词库附带的备选英文表达）匹配。这里的“已掌握”是网站的复习状态，不代表能不加调整地套用整句。

## 部署

解压 ZIP，把 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 一起上传到 GitHub 仓库根目录。在 **Settings → Pages** 选择 **Deploy from a branch**、`main`、`/(root)`。如果浏览器保留旧页面，部署后可尝试强制刷新。

本地预览请通过 HTTP 服务器，而不是直接用 `file://` 双击网页：例如在解压目录运行 `python -m http.server 8000`，打开 `http://localhost:8000/`。

## 学习记录和兼容性

沿用 v7 的浏览器本地 `localStorage` 存储键，不会因新版替换页面而主动清空已有记录。v7 中已掌握的表达仍保持原有记录；v7 中完成一次正确拼写但尚未掌握的表达，在 v8 中进行一次正确的间隔复习即可掌握。每日数据、备份导入和导出均保留。浏览器和设备之间不会自动同步，升级前建议先点击网站的「备份进度」导出 JSON。

词库内容与用户上传的 v7 完全一致；本次仅调整学习流程、提示文字和进度机制，没有批量改写表达或例句。
