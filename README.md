# IELTS Writing Lab v14｜全库 + 专项学习／复习版

这是一个适合 GitHub Pages 部署的纯静态雅思大作文观点表达训练网站。包含 **12 个主题、600 条表达**，以 v13 高频间隔复习版为基础加入 **专项学习**、**专项复习** 和主题选择页面；**表达库、原有学习记录、每日统计、固定分组及英美拼写兼容均保留**。

## 1. 四个入口，两种抽题范围

首页原有的两个入口照常使用：

- **开始新表达**：从当前通用学习范围随机抽取未学表达。每组 5 / 10 / 15 / 20 / 30 条，组内全部拼写正确一次才结束。
- **复习到期**：从当前通用范围中已学习的表达优先抽取到期项；不足时按原有条件提前巩固。

新增两个按钮：

- **专项学习**：打开主题选择界面 → 选择教育、科技、社会、政府、媒体、国际、犯罪、文化、旅游、环境、健康、工作中的一个 → 仅学习该主题尚未学习的表达。
- **专项复习**：打开同一个主题选择界面 → 选择主题 → 仅复习该主题已经学过且符合复习条件的表达；到期优先，符合时间要求时可提前巩固。

首页绿色卡片和下方「今天想怎么练？」区域均设有专项入口。主题卡片显示该主题总条数、已学习数量，以及相应的可学习／可复习数量；如果某主题没有符合条件的表达，对应选项会暂不可用。

**每组数量共用原来的两个设置**：普通学习与专项学习共享「新表达每组」数量；普通复习与专项复习共享「复习每组」数量。不额外引入另一套目标数据。

## 2. 专项与全库完全共用记忆进度

**并非重复建一套“专项词库”。** 每条表达由原有唯一 ID 标识，练习结果始终写入同一份 `state.progress`，包含：

- 首次学习 / 已掌握状态；
- 正确次数、错误次数、近期拼写结果及连续正确情况；
- 上次练习、下次复习时间及个性化间隔。

因此，从「教育类专项学习」学会的表达会计入首页的总进度及每日新学统计，并按照 v13 的间隔规则**正常进入以后全库随机复习**。同样，普通复习和「教育类专项复习」共用已掌握状态和每日复习柱状图计数，**没有两份掌握状态**。同一表达在同一模式下当天多次通过，仍按 v13 规则只计 1 条。

## 3. 不串组，并保留未完成组

v13 的固定分组机制保持不变：组内每条表达都必须正确拼写一次才能进入下一组，拼错的表达留在当前组后续再练。新增的专项组按「练习类型 + 主题」独立保存，例如 `learn:教育`、`review:科技`；旧版普通组仍以 `learn` / `review` 保存。

- 暂时切换到另一个主题，原专项组不会丢失；下次选择同一主题可以续练。
- 原有未完成的普通学习／复习组仍可以从原入口续练。
- 若表达已被某个未完成组占用，其他新建分组将暂时避开这条表达，避免同时在两个固定组中出现。
- 一个主题里如果没有可抽取的新条目，但有一些条目处于其他未完成组中，选择界面会给出提示。
- 完成专项组后，报告继续显示本组用时、错误次数及所有表达；「继续专项学习／专项复习」会继续保持当前主题。

## 4. 复习时间和拼写判定（继承 v13）

新表达：中文提示 → 显示英文表达和例句 → 隐藏答案 → 拼写一次；正确为本条 `学习1/1`。

复习：根据中文提示直接拼写；正确为本条 `复习1/1`。答错仍留在当前组重练。标准答案和例句位于拼写框下方，英式／美式规范拼写均可通过判定。

基础复习间隔约为 **12 小时、1、2、3、5、7、10、14、21、30 天**，结合历史错误率和本轮错误次数调整。已掌握内容不会从复习系统中永久移除，最长基础间隔 30 天。提前巩固仍遵守 v13 的原则：非到期表达需要距离上次练习至少 12 小时。

## 5. 学习记录与备份

**保留本地存储键** `ieltsWritingLab.v3.spelling-progress`；页面仍会尝试合并 v2 中尚未纳入的历史表达。新增分组只是保存在已有 `activeBatches` 下的新键，不改变词库 ID、历史进度、每日统计或以前组别的存储位置。

升级前请在当前网站右上角点击「备份进度」，保存 JSON。更新网站后检查总进度是否与升级前接近，以及未完成的普通学习／复习组是否能正常续练。**不要为了更新网站而清除浏览器的网站存储。**

注意：`localStorage` 与网站域名和浏览器绑定。更换域名、浏览器、无痕窗口或清除站点数据可能使网站无法读取原记录，此时需要手动导入备份。

## 6. 部署到 GitHub Pages

1. 解压 `ielts-writing-expression-trainer-v14-topic-focus.zip`。
2. 将 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 覆盖 GitHub 仓库中的对应文件。
3. 待 Pages 更新后刷新网页；如仍显示旧内容，强制刷新以更新缓存，**不要清理网站存储数据**。
4. 本地查看也可以在解压目录执行 `python -m http.server 8000`，然后在浏览器访问 `http://localhost:8000`。

**本次没有修改 `words.json` 中任何一条表达。** 网站不需要后台服务器，学习记录仅保存在用户当前浏览器中。
