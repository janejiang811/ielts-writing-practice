# IELTS Writing Lab｜观点表达记忆室（v4）

这是一个适配 GitHub Pages 的静态网站，帮助学习者通过主动回忆、语境练习、拼写回忆和间隔复习积累雅思大作文表达。

## 本轮更新

- **12 个独立主题分区**：教育、科技、社会、政府、媒体、国际、犯罪、文化、旅游、环境、健康和工作。每个主题有 50 条表达，并展示待学习、学习中、已掌握数量。
- **主题卡片式表达总库**：先浏览主题总览，再进入某一主题；进入后按完整论证句、观点与措施、积极结果、消极结果、原因分析排序。支持主题、用途和中英文关键词筛选。
- **例句语境精修**：600 条表达均提供更新后的例句；句子尽量使用清晰、自然、适合 IELTS Writing Task 2 的论证表达，并增加贴合主题的语境。部分明显不自然的核心短语也做了轻度修订。
- **新旧混合拼写练习**：默认按“2 条新表达 + 1 条已学表达”的节奏交错安排；优先插入到期或较久未复习的旧内容。答错的表达会在本轮后面重新出现一次。
- **四次顺利回忆后标记掌握**：一次正确拼写记录为一次顺利回忆；累计达到 4 次后显示“已掌握”。答错会重置该条的连续顺利回忆进度。普通卡片模式下也可通过“顺利想起”积累进度。
- 保留本地学习记录、每日目标、到期复习、浏览器朗读、学习进度导出与导入功能。

## 使用与部署

1. 解压 ZIP，确保 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 位于同一目录。
2. 可将这五个文件上传至 GitHub 仓库根目录，并在 **Settings → Pages** 中选择 **Deploy from a branch**、`main` 和 `/(root)`。
3. 也可以通过本地静态 HTTP 服务器运行。不要直接双击 `index.html` 以 `file://` 方式打开，因为浏览器通常会阻止页面读取 `words.json`。

## 词库与例句说明

- 词库共 **600 条**，12 个主题各 50 条；每个主题包括 10 条完整论证句、10 条观点与措施、10 条积极结果、10 条消极结果和 10 条原因分析表达。
- 中文释义与原资料表达是整理和练习的基础；其中少数明显不自然的英文短语已经做了轻度修订。所有例句均经过本轮编辑，用于展示表达如何放进论证语境，并非声称来自真实语料库或原 PDF 原句。
- 即使表达本身正确，能否用于某道 IELTS 题目仍取决于题目语境、因果逻辑和论证对象。请把例句作为语言练习和改写参考，不要整句机械套用。

## 学习记录与掌握判断

- 学习数据保存在当前浏览器的 `localStorage` 中，不会自动跨浏览器或跨设备同步。更换设备前请使用“备份进度”导出 JSON 文件。
- “已掌握”表示累计 4 次顺利回忆，并不代表该表达在所有题目语境下都能自然使用；实际写作中还需要判断搭配、语法和逻辑是否合适。
- 语音功能使用浏览器/设备提供的 `speechSynthesis`，没有内置录音素材。
