# IELTS Writing Lab｜观点表达记忆室（v3）

这是一个适配 GitHub Pages 的静态网站，把观点表达库升级为基于主动回忆、语境练习、拼写回忆和间隔复习的个人写作表达工具。v3 保留原 PDF 的表达与译文，并重新整理了短语条目的补充语境句与句型骨架。

## 本版本内容

- 从《浓缩版观点库（短时间备考同学适用）》中整理出 **600 条条目**：12 个主题，每个主题含 10 条完整论证句、10 条观点表达、10 条积极结果、10 条消极结果和 10 条原因分析表达。
- 四种主要入口：新表达、间隔复习、拼写回忆、表达总库。
- 卡片先展示中文提示；翻开后显示英文原表达、语境例句、中文辅助释义和用法提醒。
- 不同学习反馈会影响下一次复习间隔。需要复习的条目会在到期后重新出现。
- 记录保存在当前浏览器的 `localStorage` 中；支持导出 JSON 备份和导入备份。
- 支持浏览器内置英文朗读（`speechSynthesis`）；朗读声音由浏览器/设备提供，并非内置原声素材。
- 支持按主题、表达用途和关键词筛选。

## 如何部署到 GitHub Pages

1. 解压 ZIP。
2. 将 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 全部上传到 GitHub 仓库根目录。
3. 进入仓库的 **Settings → Pages**。
4. 选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`。
5. 保存设置，等 GitHub Pages 完成发布后打开生成的网址。

网站需要通过静态 HTTP 服务器访问，不能直接双击 `index.html` 以 `file://` 方式打开，因为页面需要读取 `words.json`。

## 内容字段

`words.json` 每条包含 `id`、`category`、`categoryName`、`type`、`zh`、`en`、`exampleEn`、`exampleZh`、`grammarTip`、`role`、`sourceLabel`、`sourceGroup`。

- `zh` 与 `en` 是从用户的 PDF 观点库中整理的中英条目，原资料的英文措辞没有被悄悄改写。
- 对原资料提供的 120 条整句，例句区直接展示原句和原中文。
- 对其余短语，例句区提供由编辑整理的语境示范与句型骨架，用于练习表达在句子中的语法位置；它们不是 PDF 原文，也不等同于真实语料库中的原声例句。正式写作前仍需结合具体题目判断搭配与逻辑。
- 原资料中的少数表达可能需要进一步检查自然度、语法和具体适用语境。本工具保留原始条目，以免将修改后的表达误标成原文；在正式写作前，建议结合题目判断并适当改写。

## 复习机制说明

本工具根据用户选择的“没想起来 / 有点模糊 / 顺利想起”设置后续复习时间。它是一个简单的本地间隔复习安排，并非对“不背单词”内部算法的复制。学习记录仅在当前浏览器保存，不会通过 GitHub Pages 自动跨设备同步。更换浏览器或设备前，可以先点“备份进度”。
