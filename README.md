# IELTS Writing Lab｜观点表达记忆室（v10：英美拼写兼容版）

本网站可以作为纯静态网页部署到 GitHub Pages。保留之前的页面风格、12 个主题分类、600 条表达、表达总库、搜索和筛选、语音朗读、本地学习记录与进度导入/导出。本轮在 v9 基础上增加英美拼写兼容判定，保留拼写框在答案上方及独立分组复习。

## 本轮改进

### v10 新增：规范的英式与美式拼写均可通过

现在不再只对照唯一的英文字母串：核对时会把**同一英文单词的规范英式／美式拼写**视为等价，但仍要求目标表达的完整词序、单复数、其他词形、介词和搭配保持准确。

例如：
- `globalisation` ↔ `globalization`
- `organisation` ↔ `organization`；`organisations` ↔ `organizations`
- `programme` ↔ `program`；`programmes` ↔ `programs`
- `offence` ↔ `offense`；`offences` ↔ `offenses`
- `subsidising` ↔ `subsidizing`；`standardised` ↔ `standardized`
- `centre` ↔ `center`；`centres` ↔ `centers`
- `ageing` ↔ `aging`；`labour` ↔ `labor`

规则基于 **200 组明确列出的英美拼写对应词**，不采用编辑距离、自动纠错或任意替换 `s/z`、`our/or` 等宽松方法。例如 `advise` 与 `advice`、`raise` 与不存在的 `raize` 不会因为外观相似而混为一谈；`practice/practise` 涉及英式英语的词性区别，也没有加入无条件等价映射。大小写、合理的空格调整以及常见弯引号、破折号字符仍按原本规则处理。

命中英美拼写替换时，核对结果会显示类似“**已认可英／美拼写差异：globalization ↔ globalisation**”，并在拼写框下方保留词库原始英文表达及例句，方便你对照和养成统一的拼写习惯。在雅思写作中建议整篇保持同一种拼写体系。

### 全量核查说明

通过程序逐条扫描了**全部 600 条正式表达**及它们的替换建议，检查了例句中出现的区域拼写。此次词库中有 **44 条正式表达（或其替换建议）** 直接包含待兼容的英美拼写词；另有部分只在例句中出现。测试覆盖了每条正式表达的原写法、可交换拼写变体及故意制造的错误拼写。**没有改写 600 条原始表达与例句**，原文件保留。

### 延续 v9 的使用体验

**1. 核对后的答案恢复到拼写框下方。** 首次学习新表达的流程仍然是“看中文猜想 → 显示英文与例句 → 隐藏答案后拼写一次”。但现在拼写区在答案区上方。提交后，输入框会保留你的拼写，标准表达、例句及提示会紧接着显示在下方，便于立即检查拼写差异。复习模式也采用相同布局：先独立拼写，核对后马上对照。

**2. 间隔复习可以独立设置每组数量。** 在首页今日计划卡片和复习界面都可选择每组 5、10、15、20 或 30 条。这项选择独立于“新表达每组”数量，修改后会自动保存在浏览器本地。到期表达只取当前筛选范围内的一组；一组完成后，点击“继续复习下一组”即可按相同数量开始下一组。如果剩余不足设定数量，就只显示剩余的到期表达。已经通过的复习不会在下一组重复出现；拼写错误的条目安排约 10 分钟后再复习，不会立即强制重写。

## 掌握规则（延续 v8）

- **新表达**：先看中文、英文和例句，再隐藏答案拼写。一次拼写正确即完成首次学习，约 1 天后进入间隔复习；错误约 10 分钟后待复习。
- **间隔复习**：只看中文直接拼写，正确一次即标记已掌握，按间隔计划安排之后的复习；错误约 10 分钟后再次到期。
- 大小写、多余空格及上文明确支持的规范英美拼写差异不影响核对；其他词形、拼写和词序仍需准确。若表达附有自然替换建议，匹配该建议也可判为正确。
- 系统通过“核对”给出即时反馈，点击“下一条”正式保存该次结果并进入后续练习。

## 安装或更新

1. 解压文件，保持 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 在同一目录。
2. 更新 GitHub Pages 网站时用这五个文件替换仓库根目录里的旧文件，等部署完成后刷新页面；如遇旧缓存，可强制刷新。
3. 本地测试请用静态服务器打开（如 `python -m http.server 8000`），不要直接用 `file://` 双击 HTML，否则浏览器可能阻止加载 `words.json`。

## 数据保存与兼容性

学习进度保存在当前浏览器 `localStorage` 中，沿用 v7/v8 的存储键 `ieltsWritingLab.v3.spelling-progress`，升级不会主动清除记录。独立复习组数作为附加设置保存，旧记录默认每组 10 条。建议更新前先通过“备份进度”导出 JSON。换设备或浏览器后可以通过“导入进度”恢复记录。

词库仍有 12 个主题、600 条表达，每个主题 50 条。例句为便于学习雅思 Task 2 的搭配和论证逻辑而编辑的材料，不代表真实考题语料中的标准原句，仍需结合题目灵活使用。
