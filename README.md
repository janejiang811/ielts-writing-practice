# IELTS Writing Lab｜观点表达记忆室（v5：拼写优先版）

这是一个可部署到 GitHub Pages 的静态网站，用来练习雅思大作文观点、措施、结果和原因表达。保留原有主题卡片、筛选、表达总库、学习目标、语音朗读与本地备份功能，本次更新集中在**拼写掌握机制**和**例句质量**。

## 本轮主要改动

- **拼写是唯一的掌握依据。** 新表达、间隔复习和强化拼写都会先要求输入英文，再显示标准答案；不再允许通过“感觉熟悉”或主观评级累计掌握进度。
- **连续四次拼写正确才算掌握。** 正确答案会增加一次连续正确记录；任何拼写错误都会把连续进度重置为 0，并将这条表达安排到约 10 分钟后重练。大小写不作为错误，连续空格会统一处理，常见弯引号和破折号会标准化；其他拼写、词形、词序和标点仍需与目标表达一致。
- **新旧内容交错练习。** 强化模式优先安排到期或较久未复习的已学表达，默认以两条新表达搭配一条旧表达的节奏进行；答错项目会在当前练习队列末尾再出现一次。
- **重写语境例句。** 600 条词库仍按 12 个主题分区，每个主题 50 条。例句重点解释表达的实际用途、条件或因果机制；措施、结果和风险类例句按具体核心表达重新配对，避免只把通用补充句接在句子后面。检查并修正了重复用词、搭配和部分不自然的核心表达。
- **保留原有界面。** 主题入口、主题总库、用途筛选、关键词搜索、每日目标、朗读和进度导入/导出继续保留。

## 使用与部署

1. 解压 ZIP，确保 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 位于同一目录。
2. 把这五个文件上传到 GitHub 仓库根目录，在 **Settings → Pages** 中选择 **Deploy from a branch**、`main` 和 `/(root)`。
3. 也可以通过本地静态 HTTP 服务器运行。请勿直接双击 `index.html` 以 `file://` 方式打开，因为浏览器通常会阻止页面读取 `words.json`。

## 词库说明

- 词库共 **600 条**，包含 12 个主题：教育、科技、社会、政府、媒体、国际、犯罪、文化、旅游、环境、健康和工作。
- 每个主题包括 10 条完整论证句、10 条观点与措施、10 条积极结果、10 条消极结果和 10 条原因分析表达。
- 英文例句和中文释义是编辑后的学习材料，不声称来自真实语料库或原 PDF 原句。例句用于帮助理解搭配和论证机制，并非可套用于任何题目的固定答案。实际写作时仍要判断论点与题目、论证对象和因果关系是否匹配。

## 学习记录和旧版本迁移

- 学习数据保存在当前浏览器的 `localStorage` 中，不会自动跨浏览器或跨设备同步。更换设备前请使用“备份进度”导出 JSON 文件。
- 旧版本中的学习记录和设置会尽可能保留，但此前靠主观自评累计的掌握等级会被重置为待拼写核验，避免把“看起来熟悉”误记为准确输出。导入旧版本备份时也采用相同规则；每日统计历史与设置会一并保留。
- “已掌握”表示当前记录已达到连续四次正确拼写的标准，并不代表这条表达在所有写作语境下都能自然使用。
- 语音功能使用浏览器/设备提供的 `speechSynthesis`，没有内置录音素材。
