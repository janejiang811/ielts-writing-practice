# IELTS Writing Lab v12｜智能复习与学习统计版

本项目为纯静态 GitHub Pages 网站，包含 12 个话题、600 条雅思大作文表达。v12 在 v11 的固定组学习模式上增加了自适应间隔复习、旧记录合并兼容、每日双柱统计和每组完成报告。无需服务器或登录，学习数据只保存在**当前浏览器**的 localStorage 中。

## 1. 学习和复习保持固定组

- 新表达：中文提示 → 显示英文表达及例句 → 隐藏答案 → 拼写判定。每条至少正确一次才能通过本组。
- 复习：根据中文提示直接拼写。每条至少正确一次才能通过本组；若拼错，则继续留在本组，完成其他未通过内容后重新练习。
- 学习与复习可以分别设置每组 5、10、15、20 或 30 条；固定组中途不会混入前后组的内容，刷新与切换模式仍可续练。
- 拼写框始终位于核对结果、标准答案和例句上方；保留英式和美式规范拼写兼容。

## 2. 自适应间隔复习

**已掌握不等于停止复习。** v12 保留每条表达的下一次计划复习时间。基础记忆间隔大致按 **1、3、7、14、30、60、90、120 天** 随成功复习逐渐拉长；这些是参考间隔重复原理的工程化时间点，并非声称复现精确的艾宾浩斯遗忘曲线。

从 v12 起，系统为每条表达记录：
- 累计已跟踪的拼写尝试次数、正确次数、错误次数；
- 最近 20 次判定结果，以及当前连续正确的次数；
- 上次练习时间、下一次复习时间、实际使用的复习间隔。

一条表达若在固定组内多次拼错，系统在**最终正确通过本组之后**仍会缩短下一次复习间隔；若最近表现稳定、持续拼写正确，间隔会逐步增加。真正拼错会降低记忆等级，但不会跳过当前组的正确判定要求。

**提前巩固：** 当今日到期条目较少或没有到期内容时，复习入口可以挑选已有学习记录、距离计划复习日期较近的表达进行提前巩固。这些表达会优先按最接近到期时间排序。不建议刚学完就马上算作复习：提前巩固要求距离上次练习至少 12 小时。复习组先选已到期条目，再用适合提前巩固的旧表达补足组数。

## 3. 旧版进度兼容

- **与 v5–v11 兼容：** 继续使用 `ieltsWritingLab.v3.spelling-progress`，保留旧版学习等级、复习次数、原计划到期日、每日完成记录和未完成固定组。
- **兼容更早的 v2：** 若浏览器里同时有 v3 和 v2 两套记录，会将 v2 中**尚未存在于 v3 中**的表达补回进度库，避免因为局部覆盖而丢失。v2 主观评价不等同于拼写掌握，因此补入项需要重新拼写验证。
- **不伪造历史数据：** v11 及之前没有完整记录每次的错误判定，也未将每日完成量准确拆分为学习和复习。因此，无法准确倒推以前的错误率或把历史完成量强行分为“新学/复习”。旧数据照常保留；v12 后的记录开始准确分类与累计错误次数。
- 仍支持网站右上角的「备份进度」「导入进度」按钮。新备份版本号为 4，依然可以导入 v3 备份。

如果换浏览器、使用无痕模式或清除网站数据，本地记录可能无法读取，请用「备份进度」导出 JSON 文件并在需要时导入。**升级前强烈建议手动备份一次。**

## 4. 每日学习统计

首页深绿色「TODAY'S PLAN」卡片右上角新增统计按钮（四根柱状线）。点击后展开**最近 14 天**的逐日柱状图：

- 米白色：当天第一次完成拼写判定的**新表达**数量。
- 浅绿色：当天第一次完成拼写判定的**复习**数量。
- 同一条表达在同一模式的同一天多次通过，只计为 1 条；当天两种模式分别计数。
- 以前只有 `doneIds`、无法分辨学习或复习的完成记录会以“历史未分类”的注释保留，不错误分配给两种柱形。

## 5. 每轮完成报告

固定组所有表达都正确一次后，完成页显示：

- **有效练习时长**：仅记录网页显示该组练习时的时间；隐藏浏览器标签、切换到表达总库、刷新后离线的时间不计入。
- **通过表达数量 / 拼写尝试次数 / 拼写错误次数**。
- **本组表达完整清单**：中英文对照，每条标明「一次通过」或「错 N 次」。

切换学习/复习模式、隐藏标签时，正在进行的固定组的时长和尝试记录会存入本地数据，回到该组后继续累计。

## 6. 部署

1. 先在原网站右上角点击「备份进度」，另存一份 JSON。
2. 解压 `ielts-writing-expression-trainer-v12-smart-review.zip`，用其中 `index.html`、`style.css`、`app.js`、`words.json`、`README.md` 覆盖 GitHub 仓库中的同名文件。
3. 等待 GitHub Pages 部署，浏览器强制刷新后访问网站。若仍显示旧版，清除页面缓存但**不要清除网站存储数据**。
4. 本地运行建议使用静态 HTTP 服务器（例如 `python -m http.server 8000`）。

本次**未更改 words.json** 中的 600 条表达和例句；所有进度迁移与间隔复习逻辑在浏览器中运行，未向任何第三方发送学习记录。
